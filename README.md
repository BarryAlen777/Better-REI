# Better-REI
REI 的性能优化附属模组，附带 EMI 风格配方树。

> 仅作为 REI 附属，不替换 REI，兼容原版 REI 逻辑，所有原生行为不变。

## ✨ 功能
### 性能优化
1. **配方/用途索引查询**
原版 R 键查询会遍历全部分类所有配方。本模组改用 REI 倒排索引，只检索命中分类，大包下提速明显，查询结果和原版完全一致。

2. **物品图集自动限流**
REI 大图集在大量物品时会造成长时间开背包卡顿。自动根据物品数量判断是否禁用图集缓存；小包维持原版行为，玩家手动设置优先。

3. **名称排序缓存**
REI 按名称排序时重复解析显示名。增加名字缓存，资源重载自动刷新，仅在名称排序模式下生效。

4. **缓存自动清理挂钩**
资源重载、KubeJS 动态添加物品等场景，自动清理全部缓存，避免脏数据。

### 新增：Ctrl+R 配方树（EMI 风格）
在物品/背包槽/手持物品上按 `Ctrl+R` 打开。
- 树状逐级展开配方/原料，带循环防护与分支上限
- 内置购物清单：读取背包存量自动计算缺口，多分支资源不会重复占用
- 支持目标数量修改、合成/用途切换、分类筛选（配置持久化）
- 逐帧展开，防止界面卡死；重载时保留展开状态与滚动位置
- 配方过多时折叠隐藏，点击查看更多

## 📌 注意事项
- 依赖 REI
- 所有优化默认开启；配方树快捷键可在游戏内修改
- 配方树数据全部取自 REI，不额外读取其他 mod 配方系统
